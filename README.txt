# Marco Loredo Professional Portfolio

This folder contains a simple one-page professional portfolio website.

## Files
- `index.html` — the website
- `styles.css` — styling

## Free publishing option: GitHub Pages

1. Create a free GitHub account if you do not already have one.
2. Create a new public repository named something like `marco-loredo`.
3. Upload both `index.html` and `styles.css` to the repository.
4. Open the repository's **Settings**.
5. Go to **Pages**.
6. Under the publishing/source section, choose the main branch and root folder.
7. Save. GitHub will provide a public website address after deployment.

A common GitHub Pages address looks like:
`https://YOUR-USERNAME.github.io/marco-loredo/`

If a service requires a root-domain-only URL and rejects subpages, GitHub Pages may still not satisfy that particular signup form. The portfolio is still useful for resumes, LinkedIn, and applications.
